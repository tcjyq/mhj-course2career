# AI 输出评测方案

## 1. 评测目标

评测只覆盖 JD 结构化提取，不把确定性评分纳入模型评测。目标是确认模型能稳定提取技能、重要程度和原文证据，并遵守数据契约。

## 2. 黄金样例

建立脱敏 JD 集合，至少覆盖数据分析、业务分析、产品、信息系统实施和开发岗位。每份样例由人工标注：规范技能、可接受别名、重要程度和证据句。

## 3. 指标

- 技能精确率：模型提取技能中人工认可的比例。
- 技能召回率：人工标注技能中被模型识别的比例。
- 重要程度准确率：已匹配技能的重要程度一致比例。
- 证据有效率：证据是否来自输入且支持判断。
- 契约通过率：响应能否通过 Pydantic 校验。

## 4. 测试方法

- 单元测试使用模拟响应，不产生 API 成本。
- Prompt 或模型变更时，对固定黄金样例离线重跑并记录模型名、日期和指标。
- 不要求生成文本逐字一致，只验证结构和语义标准。
- 发现误报时优先改进提示词或人工确认流程，不允许模型直接影响评分公式。

## 5. 上线门槛

作品集演示前，黄金样例契约通过率应为 100%，证据有效率应为 100%；技能精确率和召回率目标均不低于 85%。未达到目标时默认使用本地规则模式并标注限制。
