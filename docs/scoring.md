# 匹配评分设计

## 1. 课程技能证据分

一门课程对一项技能的证据分为：

```text
证据分 = 成绩 × 30%
       + (自评 / 5 × 100) × 25%
       + (课程技能映射强度 × 100) × 35%
       + min(学分 / 5, 1) × 100 × 10%
```

设计理由：映射强度决定课程是否真正相关；成绩与自评分别提供客观和主观学习证据；学分仅占较小权重且设置上限，避免高学分课程支配结果。

## 2. 单项技能支撑分

同一技能可能由多门课程支撑。MVP 采用最高证据分作为技能支撑分，避免简单累加导致重复课程无限抬高分数。所有命中课程仍作为证据展示。

状态阈值：

| 支撑分 | 状态 |
|---:|---|
| `>= 70` | 较强支撑 |
| `>= 40 且 < 70` | 有一定基础 |
| `< 40` | 当前缺口 |

## 3. 综合匹配分

岗位技能权重为：核心 `1.0`、优先 `0.7`、加分 `0.4`。

```text
综合匹配分 = Σ(技能支撑分 × 重要程度权重) / Σ(重要程度权重)
```

## 4. 局限

- 课程名称规则无法读取真实教学大纲、作业质量和项目经历。
- 最高证据法强调最相关课程，不衡量跨课程知识叠加。
- 阈值和权重是 MVP 的可解释基线，尚未通过招聘结果校准。
- 分数只能用于学习优先级讨论，不能解释为录用概率。
