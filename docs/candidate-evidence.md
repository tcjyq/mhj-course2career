# 求职证据导航

本页用于快速核对项目能证明什么。项目是学习决策原型，面向AI应用／企业数字化、解决方案、B端技术产品、实施支持和数据分析方向；不证明算法研究能力、生产落地或就业效果。

| 能力 | 可核验实现与测试 | 面试可以讲述 | 局限 |
| --- | --- | --- | --- |
| 需求拆解与验收 | [优化复核](optimization-review.md)、[业务回归](../tests/test_optimization.py) | 将课程误推断、完整度、门槛、引用、演示与学习建议拆成可对照输入 | 真实用户任务成功率未测 |
| 数据与证据边界 | [课程词典](../data/course_skill_map.json)、[映射器](../src/course2career/course_skill_mapper.py) | Java不能凭“程序设计”支持Python，通用可视化不能支持具体BI产品 | 课程名称无法代表完整教学内容 |
| AI产物检查 | [引用核对](../src/course2career/jd_analyzer.py)、[确认界面](../src/course2career/ui/analysis_page.py) | 区分引用能定位和技能推断成立，保留人工修正路径 | 原文出现不代表逻辑正确；固定响应不是实测提取准确率 |
| 规则设计与解释 | [适配度引擎](../src/course2career/adaptability.py)、[评分回归](../tests/test_adaptability_scoring.py) | 五维评分、独立门槛、贡献账本与多来源说明 | 权重未经过招聘结果统计校准，自述不等于独立验证 |
| 场景与轻量交付 | [三类合成输入](../data/demo_cases/cases.json)、[界面测试](../tests/test_app.py) | 演示材料不足、基础相关、门槛失败三种情况；任务带交付与验收 | 合成案例不是真实候选人或人工gold |
| 兼容与回归 | [导出](../src/course2career/report_exporter.py)、[模型](../src/course2career/models.py) | 可选新字段、旧报告读取、CSV旧五列、保留未知和明确没有的区别 | 历史来源缺失不能补造，无法从旧快照恢复原始材料 |

## 作者与AI贡献

本次任务由用户提供优化规范并授权分析和本地实施；代码、测试、文档修改和自动验证由Codex辅助完成。不能据此倒推项目历史上每个模块是谁独立实现。本人历史贡献、独立完成部分、投入时长及决策过程均待本人确认。

## 简历建议同步段落

Course2Career｜AI辅助课程能力与岗位要求映射原型。采用“JD技能提取—人工确认—确定性规则评估”流程，展示课程、项目、实习与迁移依据，区分资料完整度和硬门槛；通过Codex辅助修正课程名称误映射、增加JD引用核对、三类合成求职案例及带交付物和验收标准的学习任务，并完成本地回归验证。项目不预测录用概率，业务效果尚未通过真实用户或人工标注校准。本人具体职责待确认后再填入正式简历。

## 作品集建议同步段落

这个原型尝试回答“已有材料能支持哪些岗位要求，还缺什么证据”。本次优化从可复现错误出发：通用编程不再被当作Python，通用可视化不再直接证明Power BI或Tableau；来源说明保留直接提及、间接／迁移、自述与未体现的差别，AI引用可以与JD逐字或规范化核对。实施支持、AI解决方案与数据分析三类合成演示通过同一规则引擎生成解释和可验收学习任务。交付范围是本地代码、测试和文档；不声称已发布、已落地或提高实测准确率。AI协作方式与本人贡献应如实注明。
