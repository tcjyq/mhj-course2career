# ADR-001：使用五维大学生岗位适配度模型

## 状态

Accepted

## 日期

2026-07-26

## 背景

初版 Course2Career 使用课程证据与 JD 技能进行加权匹配。测试 AI 大模型应用开发实习岗位时，结果只有 `16.4/100`，主要原因是模型过度依赖技能名称完全匹配：

- 大学生尚未接触某项技能时容易直接接近零分；
- 项目、实习、专业背景和成长速度无法补偿技能缺口；
- 学历、毕业年份和到岗时间等硬门槛与能力混在同一个分数中；
- 用户只能看到结果，无法知道具体证据造成了多少加分或扣分。

目标用户是准备实习和校招的大学生，因此模型需要反映“当前证据、岗位条件和可成长距离”，而不是复制社会招聘的熟练技能筛选。

## 决策

将“技能匹配评分”升级为 Career Adaptability Model v2.1：

1. 使用五维适配度：
   - 技术技能 25%；
   - 教育背景 20%；
   - 项目实践 20%；
   - 实习实践 25%；
   - 学习与就业潜力 10%。
2. 最低学历、专业、毕业年份、到岗时间和城市作为独立硬门槛，不乘入适配度。
3. 技能没有直接证据时保留15分学习基础，不直接记零。
4. 允许课程、项目、实习和版本化技能迁移共同提供证据。
5. 未填写信息使用50分中性值并降低可信度；明确选择“目前没有”才按缺少证据处理。
6. 使用 `最终适配度 = 50 + Σ加减分` 的解释账本，所有条目可追溯到维度、原因和证据。
7. 结果明确标注“不代表录用概率”。

## 考虑过的方案

### 继续使用技能加权平均

- 优点：简单、容易实现。
- 缺点：忽略大学生的课程迁移、项目、实习和成长潜力；容易产生过低分。
- 结论：拒绝。

### 让大模型直接给出适配度

- 优点：能够综合自然语言信息。
- 缺点：结果不可稳定复现，难以对账，容易受提示词和模型版本影响。
- 结论：拒绝。大模型只负责JD语义提取。

### 直接预测录用概率

- 优点：表面上更接近求职者最关心的问题。
- 缺点：没有真实、合规、无偏的录用数据；会制造虚假确定性并放大教育背景偏差。
- 结论：拒绝。

### 将硬门槛直接作为总分乘数

- 优点：能够快速压低不符合要求的岗位。
- 缺点：把资格限制误解为个人能力。例如毕业年份不符不代表技术能力为零。
- 结论：拒绝，改为独立状态。

## 影响

### 正面影响

- 结果更符合大学生实习和校招场景；
- 项目、实习和成长证据可以合理补偿技能不足；
- 用户能够看到每项加减分；
- 硬门槛、能力适配和数据可信度不再混淆；
- 模型可以通过确定性测试稳定回归。

### 代价与限制

- 输入项增加，用户需要补充教育、项目和实习信息；
- 院校、项目质量、实习信号和潜力包含人工规则或主观输入；
- 当前权重尚未使用真实招聘结果进行统计校准；
- 模型只能用于学习和投递决策辅助，不能作为招聘决策系统。

## 后续要求

- 调整权重、院校信号、迁移规则或阈值时必须更新 `docs/scoring.md`；
- 必须保留代表性大学生案例、硬门槛、缺失信息和解释账本回归测试；
- 如果未来更换模型，应新增 ADR 并说明如何处理公平性、可解释性和历史报告兼容。
