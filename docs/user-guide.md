# Course2Career 使用说明

## 这个网站能做什么

Course2Career 会把你学过的课程和一份招聘要求放在一起比较，帮你回答三个问题：

1. 我现在的课程能支撑哪些岗位技能？
2. 我离目标岗位还缺什么？
3. 接下来应该先学什么、做什么项目？

分析结果适合用来安排学习和准备作品集，不是招聘录用概率，也不能代替真实项目、实习经历和面试表现。

## 第一次使用

打开 [在线 Demo](https://mhj-course2career.streamlit.app/)，从左侧进入“个人分析”。不注册也能使用本地规则模式；注册 Free 账户后，分析记录可以显示在当前账户中。

### 第一步：准备课程表

点击“下载课程Excel模板”，在模板的“课程信息”页填写课程。不要修改表头。

| 字段 | 怎么填 | 例子 |
| --- | --- | --- |
| 课程名称 | 每门课一行，名称不要重复 | 数据库原理 |
| 学分 | 大于 0、不超过 20 | 3 |
| 成绩 | 0 到 100 | 88 |
| 课程类别 | 按学校实际分类填写 | 专业必修 |
| 自评掌握程度 | 1 到 5，5 表示掌握最好 | 4 |

上传 `.xlsx` 文件后，页面会显示成功导入的课程。若某一行有问题，系统会指出 Excel 行号和错误原因；错误行不会参加分析。

### 第二步：粘贴岗位 JD

把招聘信息中的岗位名称、岗位职责和任职要求一起粘贴到“目标岗位JD”。内容越完整，提取出的技能越有参考价值。

技能提取有三种方式：

- **本地规则**：不调用大模型、不消耗 AI 额度，适合第一次体验和公开 Demo。
- **系统AI**：使用平台配置的模型，按账户的每日额度计数。
- **开发者API Key**：只对 Developer 和 Admin 开放，使用用户自己保存的模型密钥。

选好方式后，点击“提取岗位技能”。

### 第三步：确认技能

系统会列出识别到的技能、重要程度和原文证据。你可以：

- 取消不应参加分析的技能；
- 修改技能名称或重要程度；
- 补充遗漏的技能。

确认至少保留一项技能，再点击“生成匹配报告”。

### 第四步：看懂报告

- **综合匹配分**：课程对这份 JD 所需技能的整体支撑程度，满分 100。
- **支撑分**：某项技能能从你的课程中得到多少支持。
- **支撑课程**：系统作出判断时参考了哪些课程。
- **当前优势**：已有课程支撑较强的技能。
- **薄弱技能**：目前课程证据不足、值得优先补齐的技能。
- **推荐学习路线**：按优先级给出的学习目标、行动、练习项目和完成标准。

你可以下载 Markdown 总报告，或下载 CSV 技能明细继续整理。

## 账户与 AI 额度

- 游客每天有 2 次系统 AI 体验额度。
- Free 账户每天有 5 次系统 AI 额度，并可查看最近分析。
- Pro 和 Developer 是产品能力演示，当前会员页面不会收费，也不会真正改变套餐。
- 本地规则模式不消耗 AI 额度。

额度按东八区自然日统计，可在左侧“AI额度”页面查看。

## 隐私提醒

- 使用 AI 模式时，岗位 JD 会发送给所选模型供应商。
- 课程表不会放入模型 Prompt。
- 请不要粘贴身份证号、电话、住址、未公开招聘资料或其他敏感信息。
- 不要在公共电脑上保存自己的 API Key。

在线 Demo 使用 SQLite，适合作品展示，不适合作为长期数据存储。部署环境重启或重建后，账户和历史记录可能被清空。重要报告请及时下载。

## 常见问题

### 上传后提示缺少列

请重新下载模板，并确认五个表头没有改名：课程名称、学分、成绩、课程类别、自评掌握程度。

### 为什么有些课程没有支持任何技能

当前映射主要依据课程名称和内置技能关系。课程名称太宽泛时，系统无法知道具体教学内容。可以把结果当作初步整理，而不是最终判断。

### 为什么系统 AI 不能使用

可能是当日额度已用完、平台没有配置相应模型，或模型供应商暂时不可用。你仍可切换到“本地规则”完成分析。

### 匹配分低是不是不适合投递

不是。分数只反映课程证据和 JD 技能之间的匹配情况，没有计算项目、竞赛、实习和自学经历。它更适合帮助你找到下一步补强方向。

### 注册后为什么看不到以前的游客分析

游客数据和登录账户是分开的。请登录后重新生成一次报告，系统才会把记录保存到该账户。
