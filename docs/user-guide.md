# Course2Career 使用说明

## 这个网站能做什么

Course2Career 会把你的课程、教育背景、项目、实习和成长条件与一份招聘要求放在一起比较，帮你回答四个问题：

1. 我是否满足岗位明确写出的学历、专业和到岗条件？
2. 我现在有哪些可以验证的岗位能力证据？
3. 为什么系统给出这个岗位适配度？
4. 我离目标岗位还缺什么，接下来应该补哪些能力模块？

分析结果适合用来安排学习、投递和准备作品集，不是招聘录用概率，也不能代替招聘方筛选、背景核验和面试表现。

## 第一次使用

打开 [在线 Demo](https://mhj-course2career.streamlit.app/)，从左侧进入“个人分析”。不注册也能使用本地规则模式；注册 Free 账户后，分析记录可以显示在当前账户中。

### 第一步：准备课程表

点击“下载课程Excel模板”，在模板的“课程信息”页填写课程。不要修改表头。

| 字段 | 怎么填 | 例子 |
| --- | --- | --- |
| 课程名称 | 每门课一行，名称不要重复 | 数据库原理 |
| 学分 | 大于 0、不超过 20 | 3 |
| 成绩 | 0 到 100 | 88 |
| 课程类别 | 按学校实际分类填写 | 专业必修 |
| 自评掌握程度 | 1 到 5，5 表示掌握最好 | 4 |

上传 `.xlsx` 文件后，页面会显示成功导入的课程。若某一行有问题，系统会指出 Excel 行号和错误原因；错误行不会参加分析。

### 第二步：补充个人经历和到岗条件

按实际情况填写：

- 学历、院校类型、专业和核心课程表现；
- 项目使用的技能及项目质量；
- 实习岗位、企业、技能、工作深度和成果；
- 学习距离、近期成长、求职准备和岗位投入意愿；
- 毕业年份、每周到岗天数、可连续实习月份和意向城市。

“暂未填写”和“目前没有”含义不同：

- 暂未填写：系统使用中性值，不加分也不扣分，但降低结果可信度；
- 目前没有：表示明确缺少项目或实习证据，会产生相应扣分。

岗位硬门槛只填写 JD 明确写出的要求，不要自行猜测。

### 第三步：粘贴岗位 JD

把招聘信息中的岗位名称、岗位职责和任职要求一起粘贴到“目标岗位JD”。内容越完整，提取出的技能越有参考价值。

技能提取有三种方式：

- **本地规则**：不调用大模型、不消耗 AI 额度，适合第一次体验和公开 Demo。
- **系统AI**：使用平台配置的模型，按账户的每日额度计数。
- **开发者API Key**：只对 Developer 和 Admin 开放，使用用户自己保存的模型密钥。

选好方式后，点击“提取岗位技能”。

选择 DeepSeek 时，页面会显示 Auto-Safe 优先顺序。系统只会在已通过本项目兼容性验证、且官方目录当前可用的模型中选择；如目录暂时不可用，会使用缓存或固定回退模型，不会自动启用未知新模型。

### 第四步：确认技能

系统会列出识别到的技能、重要程度和原文证据。你可以：

- 取消不应参加分析的技能；
- 修改技能名称或重要程度；
- 补充遗漏的技能。

确认至少保留一项技能，再点击“生成岗位适配度报告”。

### 第五步：看懂报告

- **岗位适配度**：技术、教育、项目、实习和潜力五个维度的加权结果，满分 100。
- **硬门槛**：学历、专业、毕业年份、到岗时间和城市等明确限制，独立于适配度显示。
- **数据完整度与可信度**：说明当前输入是否足以支持稳定判断。
- **维度评分**：展示技术技能、教育背景、项目实践、实习实践和学习潜力。
- **为什么是这个分数**：从 50 分基线开始，逐项列出加分、扣分、原因和证据。
- **技能支撑分**：某项技能能够从课程、项目、实习或迁移基础中得到多少支持。
- **能力模块路线**：把相关技能缺口合并为最多 8 个能力模块，并给出可验证成果。

你可以下载 Markdown 总报告，或下载 CSV 技能明细继续整理。

### 重新打开历史报告

登录用户可在页面底部的“最近分析”选择记录并点击“重新打开这份报告”。系统只恢复报告结果，不回填课程文件、JD 原文和候选人表单。Career Adaptability Model v2.1 上线前保存的记录会显示为“旧版技能匹配报告”，分数沿用生成时的旧口径，不应与当前五维岗位适配度直接比较。

## 账户与 AI 额度

- 游客每天有 2 次系统 AI 体验额度。
- Free 账户每天有 5 次系统 AI 额度，并可查看最近分析。
- Pro 和 Developer 是产品能力演示，当前会员页面不会收费，也不会真正改变套餐。
- 本地规则模式不消耗 AI 额度。

额度按东八区自然日统计，可在左侧“AI额度”页面查看。

## 隐私提醒

- 使用 AI 模式时，岗位 JD 会发送给所选模型供应商。
- 课程、教育、项目、实习和潜力资料只参与本地确定性评分，不作为 JD 技能提取 Prompt。
- 请不要粘贴身份证号、电话、住址、未公开招聘资料或其他敏感信息。
- 不要在公共电脑上保存自己的 API Key。
- 保存或更新 API Key 后，输入框应立即恢复为空；如果仍显示完整密钥，请停止使用并联系维护者。

在线 Demo 使用 SQLite，适合作品展示，不适合作为长期数据存储。部署环境重启或重建后，账户和历史记录可能被清空。重要报告请及时下载。

侧边栏页面会隔离显示；若浏览器保留了旧版本前端资源，可刷新一次页面获取最新版本。

## 常见问题

### 上传后提示缺少列

请重新下载模板，并确认五个表头没有改名：课程名称、学分、成绩、课程类别、自评掌握程度。

### 为什么有些课程没有支持任何技能

当前映射主要依据课程名称和内置技能关系。课程名称太宽泛时，系统无法知道具体教学内容。部分相邻技能可以提供有限迁移证据，但迁移不能替代真实项目。

### 为什么系统 AI 不能使用

可能是当日额度已用完、平台没有配置相应模型，或模型供应商暂时不可用。你仍可切换到“本地规则”完成分析。

### DeepSeek 更新后网站会自动使用新模型吗

已验证模型之间可以自动切换。官方新增但尚未验证的模型只会触发维护提醒，不会立即上线；维护者需要先验证结构化输出、Token 用量、中文 JD 效果和回退行为。这可以避免“自动更新”把公开 Demo 变成不可控试验。

### 适配度低是不是不适合投递

不是。适配度反映当前填写证据与目标岗位之间的相对距离，不代表录用概率。先检查是否存在硬门槛，再查看具体扣分项是否能够通过项目、实习或学习补齐。

### 为什么没有填写的项目没有被扣分

系统不会把“没填”擅自解释成“没有”。暂未填写使用中性值，但会降低数据完整度；只有明确选择“目前没有项目”时，系统才按缺少项目证据处理。

### 为什么院校和学历会参与评分

它们在现实招聘中可能影响简历筛选，因此作为教育维度中的市场信号参与解释。但它们不代表个人能力上限，权重受到限制，项目、实习和成长证据仍能影响整体适配度。

### 为什么硬门槛不直接把总分变成零

硬门槛和能力适配是两个问题。例如毕业年份不符合，不等于技术能力为零。系统会明确提示“存在硬性门槛”，同时保留五维能力分析，方便判断是否应该换岗位或调整投递范围。

### 注册后为什么看不到以前的游客分析

游客数据和登录账户是分开的。请登录后重新生成一次报告，系统才会把记录保存到该账户。
