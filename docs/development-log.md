## 2026-07-23 开发者API Key与多供应商模式

### 本阶段目标

### 技术决策

- 加密主密钥不进入数据库或代码仓库，避免数据库泄露后可直接解密。
- 本地规则模式保持独立，不要求任何API Key。

## 2026-08-07 开发者 API Key 输入状态清理

### 问题与修复

- 真实浏览器测试发现，开发者 Key 加密保存成功后，密码输入框仍保留完整明文，浏览器可访问性快照可能读取该值。
- 根因是保存后立即执行 `st.rerun()`，表单自动清空尚未稳定生效。
- 改为 Streamlit 表单提交回调：回调内完成加密保存，并在成功或校验失败后清空密钥输入状态。
- 真实浏览器复测发现固定组件标识仍会让当前 DOM 暂时保留输入值；进一步改为提交后递增表单版本并创建全新密码组件。
- 删除真实浏览器测试产生的临时快照目录；测试和文档不包含真实凭证。

### 回归验证

- 增加 Streamlit AppTest，验证保存后 API Key 输入框为空且组件标识已经更新。
- 118 项自动化测试全部通过；
