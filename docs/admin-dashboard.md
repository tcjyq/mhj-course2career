# 管理员Dashboard

## 当前范围

管理员Dashboard是现有Streamlit应用中的一个轻量管理视图，不是独立后台系统。只有`admin + Admin`主体能够访问查询和修改服务。

## 系统概况

| 指标 | 口径 |
|---|---|
| 用户数量 | `users`注册用户总数，不包含游客 |
| 今日分析次数 | 东八区自然日内新增的`analysis_records`数量 |
| AI调用次数 | `api_usage`累计记录数，包含成功、失败和预占记录 |
| Token消耗 | 累计`input_tokens + output_tokens` |
| 预计费用 | 累计`api_usage.cost`，仅用于运营估算 |

Token来自模型供应商成功返回的 usage 字段。费用根据部署环境中配置的每百万
Token单价估算；单价未配置时费用保持0，但Token仍会记录。历史调用缺少usage时
按0计算，预计费用仅用于预算观察，不作为供应商账单依据。

## 用户管理

管理员可以：

- 查看用户名、角色、套餐和注册时间。
- 将用户调整为Free、Pro、Developer或Admin。
- 通过`MembershipService`同步更新角色和套餐。

页面和管理服务不会返回密码哈希、API Key密文或其他敏感字段。为避免锁死后台，管理员不能在当前会话中取消自己的Admin权限。

## 页面结构

```text
管理员Dashboard
├── 系统概况
│   ├── 用户数量
│   ├── 今日分析次数
│   ├── AI调用次数
│   └── Token消耗
├── AI成本
│   └── 预计费用
└── 用户管理
    ├── 选择用户
    ├── 修改套餐
    └── 脱敏用户表格
```

## 暂不实现

- 独立管理站点
- 用户搜索、分页和批量操作
- 复杂图表与趋势分析
- 支付、订单和退款管理
- API Key查看
- 操作审计日志

用户规模增长后，可在不改变权限与仓储接口的情况下增加分页、审计和独立API层。
